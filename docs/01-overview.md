# 01 — Overview

**Project:** Aroma Parfum (Tashkent) — premium editorial perfumery site.
**Direction:** Aesop × Maison Margiela — quiet luxury, ivory/ink palette, Fraunces italic + JetBrains Mono.
**Audience:** UZ/RU-speaking customers; primary CTA is in-store visit + custom flacon fills.
**Differentiator:** Custom 10ml flacon refilled with a chosen original fragrance.

## Tone of voice

- Russian copy, restrained, no exclamation marks.
- Italic serif for emotional lines, mono caps for labels and meta.
- Never say "luxury" — show it.

## Single source of structure

`index.html` (single file, ~2200+ lines). All CSS + JS inline.
